<objective>
Declutter the Subtítulos tab: wrap the **sample-text** textarea (FONT-01) and the **browse-fonts** grid (FONT-02) in collapsible disclosure sections that are **COLLAPSED by default**. Both sections must remain fully functional when expanded — collapsing must NOT change the sample-text data flow (`sampleText → textToCaptionPages → captionPages → PreviewPlayer`) and must NOT move the sample-text section off the top of the column.

Purpose: The user wants the fonts area decluttered — the sample text and the font browser should not take up vertical space by default; they expand on demand.
Output: A new reusable `CollapsibleSection` disclosure component + its test, and `PreviewApp.tsx` updated to wrap both sections in it.
</objective>

Design-system rules that apply here (from sketch-findings):
- The collapsible disclosure is a **pure expand/collapse**, NOT an on/off toggle. Do NOT reuse the `FxBlock` switch idiom from `StyleControls.tsx` — its switch reads as "activado/apagado", which would wrongly imply the section is disabled. Build a header with a rotating chevron (▸ collapsed / ▾ expanded) instead.
- Color discipline: the disclosure header uses neutral/`--accent` tokens only. NEVER `--action` (green is reserved for the Render CTA in the header).
- Tokens: reuse the OKLCH token set already used in PreviewApp (`--surface`, `--border`, `--text`, `--accent`, `--s-*`, `--t-*`, `--r-sm`, `--dur`, `--ease`). Motion ≤ 250ms ease-out; respect `prefers-reduced-motion`.
