Tone stays a single select applied to all (META-06).

Purpose: The user wants one click to generate metadata for every network, and to switch between networks via tabs instead of a dropdown.
Output: Batch endpoint in `server.ts`, reworked `MetadataPanel.tsx`, updated `metadata-panel.test.tsx`, new supertest coverage in `metadata-api.test.ts`.
</objective>
